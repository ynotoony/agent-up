# 决策背景

本目录保存「为什么某些条款不再出现在安装面」的背景档案。它不承载规则、不作为第二权威，只在维护者问「这条以前管什么、现在谁管」时提供答案。

## 目录清单

| 名字 | 地位 | 功能 |
| --- | --- | --- |
| `README.md` | 目录索引 | 说明本目录用途与读法。 |
| `decisions.md` | 决策背景档案 | 80 条旧规则块逐条登记：原条 ID｜处置（删除／保留）｜为什么｜兜底所在（核心规则或脚本/手册）。 |

## 读法

- 只找「谁管这条」→ 看 `decisions.md` 的兜底列，再读 `../templates/core.md.tmpl` 对应 C 编号。
- 判断某条是否仍是硬要求 → 以 `rules/core.md` 与流程三件为准；本目录的结论不构成要求。
- 包内面（`../protocol/`、`../adapters/`）的规则块未删除、只是不安装，其条目在表内标为「保留」。

安装面不复制本目录：目标项目只拿到 9 件治理文件，背景档案留在包内。
